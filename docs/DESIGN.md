# CoverWeave product design

The local ui-ux-pro-max engine was run before any frontend source was written.
Queries: permission marketplace fintech calm spacious (design system), then
B2B marketplace agreements minimal (one narrower retry); keyboard focus modal
(ux domain); routing forms async state (React stack).

Verified results: Accessible & Ethical style, professional B2B navy/blue palette
and Plus Jakarta Sans typography. React results support controlled forms and
explicit async error handling. UX top result is visible keyboard focus across
modal controls. All match the web product's jobs and platform.

The engine's marketing pattern suggested Contact Sales, security badges and
case studies on both queries. No verified database match for an application
navigation pattern remained after the retry. That pattern is not persisted or
implemented. The route map is explicitly general product guidance from the
user-approved blueprint; no fabricated certification, adoption or testimonial.

## Verified tokens

Primary #0F172A / white; secondary #334155 / white; CTA #0369A1 / white;
background #F8FAFC; foreground #020617; card white; muted #E8ECF1;
muted foreground #475569; border #E2E8F0; destructive #DC2626 / white;
focus ring #0F172A. Heading and body: Plus Jakarta Sans, 400/600/700/800.
Keep 16px body, comfortable line height and bounded prose measure. Functional
cards, large labelled actions, restrained navy structure, blue only for action.
No purple gradients, emoji icons, decorative counters or raw method dashboard.

## Across every page

Welcome uses clear purpose/limits and a start action. Workspace provides search,
status filter and canonical-history links. New agreement uses a two-step
controlled form. Detail orders exact terms, next role action, then result/history.
Credits prioritizes own withdrawable GEN. Guide explains workflow/limits and
provides a restrained integration reference. Account controls wallet selection
and logout. Shared header, footer, spacing, controls and typographic hierarchy.

Minimum 44px controls, 3px visible focus, semantic headings/labels, skip link,
native dialog with focus containment/Escape, meaningful icon text, no color-only
status. Use SVG icons from one family. Responsive 375/768/1024/1440 layouts,
wrapping addresses, no horizontal overflow. Reduced-motion disables decorative
transitions; async status region remains readable without animation.

Do not redesign these pages when wiring the SDK or deployed address.
